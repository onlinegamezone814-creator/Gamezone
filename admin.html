Online Game Zone · Admin

Add a game

Icon is optional (square image works best). Games appear on the website in this order.

Slider pictures

These are the slides at the top of the website. Add as many pictures as you like: choose several at once. The whole picture is always shown, never cropped. Pictures that are wide (16:9, for example 1280 x 720) fill the slider best. Under each picture you can write a heading and some text, and it is shown on the picture. Leave the boxes empty to show the picture alone.

Add a payment method

The link and the number / ID are optional. A number / ID is shown under the name and copied when a visitor taps it. When you add a link, the method becomes a tap-to-open link on the website (it must start with https://). Icon is optional.

Visitors

Anonymous statistics from your website. You cannot see names or phone numbers here. Your own visits are not counted once you have logged in to this panel on that browser. Location is only an estimate from the visitor's time zone.
