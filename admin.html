Add a game

Icon is optional (square image works best). Games appear on the website in this order.

Offer slides

Each offer is one slide at the top of the site. If you add a banner image, the image is shown instead of the text.

Add a payment method

The link and the number / ID are optional. A number / ID is shown under the name and copied when a visitor taps it. When you add a link, the method becomes a tap-to-open link on the website (it must start with https://). Icon is optional.

Contact links

These are used by the WhatsApp, Telegram, Facebook and Email buttons and the footer.
